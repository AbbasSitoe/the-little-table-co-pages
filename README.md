## Brief Description

The Little Table's Co.is a fictional children’s event planning and catering company specializing in themed birthday parties and small celebrations. The company provides pre-planned event packages that combine catering, decorations, entertainment and event setup, giving parents and families a convenient way to organize memorable celebrations. ## Website Objectives

The main objectives of the website are to:

- Present The Little Table Co. and its services.
- Display event packages with prices and recommended guest numbers.
- Showcase available event themes and pre-planned templates.
- Provide information about catering, decorations and entertainment services.
- Allow potential customers to submit enquiries.
- Provide a simple and user-friendly browsing experience.
- Present the company's brand identity consistently across the website.
