## Project Overview

The Little Table Co. is a fictional children's event planning and catering company created as part of the Web Development (Introduction) course.

The website is designed to present the company's event planning services, celebration packages, themed event templates and enquiry process. It provides parents and guardians with an organised way to explore available services and submit their event requirements.

The website focuses on creating a friendly, professional and visually consistent brand experience while keeping the navigation and content simple and accessible.

---

## Website Objectives

The main objectives of the website are to:

- Present The Little Table Co. and its services.
- Display celebration packages with pricing and recommended guest numbers.
- Showcase themed event templates.
- Provide information about the company's services and approach.
- Allow potential customers to submit event enquiries.
- Provide contact information and customer testimonials.
- Showcase event-related imagery through the website gallery and themed content.
- Maintain a consistent visual identity throughout all pages.
- Provide a responsive browsing experience across desktop, tablet and mobile devices.

---

## Website Features

The completed website includes:

### Home Page

- Company introduction and hero section.
- Calls-to-action for planning a party and viewing packages.
- Overview of services.
- Featured celebration packages.
- Trending event themes.
- Reasons to choose The Little Table Co.
- Final enquiry call-to-action.

### About Page

- Company introduction.
- Background and beginnings.
- Mission and vision.
- Target audience.
- Primary services.
- Safety and service approach.
- Call-to-action for contacting the company.

### Packages Page

Three celebration packages are presented:

- **Mini Celebration** – R2,500
- **Classic Celebration** – R4,500
- **Ultimate Celebration** – R8,500

Each package provides information about:

- Package pricing.
- Recommended number of guests.
- Included services.
- Additional service options.
- Enquiry links.

### Templates Page

The website provides themed event concepts including:

- Princess
- Superhero
- Football
- Space
- Jungle
- Safari

Each template provides information about the theme, colour scheme, table setup, catering options, party activities and matching desserts.

### Enquiry Page

A booking enquiry form allows customers to provide:

- Personal details.
- Contact information.
- Preferred event date.
- Number of children.
- Child's age.
- Preferred package.
- Preferred theme.
- Venue or location.
- Catering requirements.
- Additional event requirements.

### Contact Page

The contact page includes:

- Email address.
- Telephone contact.
- Operating hours.
- Social media links.
- Event gallery.
- Customer testimonials.
- Contact message form.

---

## Design Approach

The website uses a consistent visual identity across all pages.

The design focuses on:

- Clear visual hierarchy.
- Consistent typography.
- Reusable styling patterns.
- Accessible navigation.
- Responsive layouts.
- Clear calls-to-action.
- Consistent spacing and alignment.
- A friendly and professional children's event aesthetic.

The colour palette was developed using Coolors based on colours selected from an existing visual reference.

---

## Responsive Design

The website has been styled to provide a responsive experience across:

- Desktop screens.
- Tablet screens.
- Mobile devices.

CSS media queries are used to adjust layouts, spacing, navigation, typography and content presentation for smaller screen sizes.

Particular attention was given to the mobile layout to ensure that content remains readable and usable on smaller displays.
